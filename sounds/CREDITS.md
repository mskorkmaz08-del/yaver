# Sounds

Yaver is silent: interface sounds were removed in v40 and the background music in v55.
The music file is no longer shipped; tools/academy.py can render it again.

- Former `academy.mp3`: "Academy", a hopeful A-minor piece for piano, escapement ticks, cello, double bass,
  French horn, violin, flute, harp and xylophone glints (tools/academy.py), composed and rendered
  for Yaver from the recorded instrument samples of the
  [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) npm packages (MIT licence).
  Same licence as the app.
- `tools/mech_sfx.py` made the earlier synthesized interface sounds (v28 to v34); kept for reference.

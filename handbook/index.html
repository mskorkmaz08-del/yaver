06 · course engine

The day-by-day course

Numbers below are read from data/course/course.json.

One path, no guessing

Every lesson runs in the same order, and nothing asks about something you haven't been taught. Recall only asks about lessons you've finished: each question names the lesson it comes from, questions from lessons you haven't done are skipped, and exit questions from your latest finished lessons fill in. The first example shows a worked example with its result, then Learn explains it, then practice and the exit ticket. Every question has a don't know yet button: it shows the answer and offers a lesson from the tutor, and on a scored question it counts as wrong. tests/validate-course.mjs enforces the rules: each recall question must name an earlier lesson, and no first example may ask you to predict or guess. Algorithm lessons in weeks 1–7 also list optional LeetCode problems that only need what's been taught.

A workshop in every lesson

Each lesson is written in a calm sepia notebook (on a laptop, two pages side by side, like a book in Apple Books, js/notebook.js) with a workshop: one of 13 simulators chosen from the lesson's track and title by js/sims.js. Circuits with flowing charge, sorting and search, graphs, data structures, vectors and matrices, slopes and gradient descent, probability, tables moving through SQL and pandas, C++ memory, git branches, the shell, and a code tracer that runs the lesson's Python on the phone (Pyodide) and steps through it line by line. Each one loads only when its lesson opens and pauses offscreen; timelines ease between states so stepping and scrubbing stay smooth.

    09 · specifications

    For engineers

    Interaction rules (Mark II, v32): one lit gold action per screen; titles big and left aligned; controls float above content and tuck away on scroll; anything can be done from the command bar (hold the Yaver gear, or ⌘K, in js/command.js); changes happen at once with Undo instead of confirmation; haptics only for moments that matter; screens slide in from the side of the tab they come from; timers pause and reset separately; focus mode is the notebook alone, full screen. Skills (v33, js/skills.js): every lesson, test, problem, study minute, task and Çetele count becomes XP in six areas, drawn as a hexagon with the shape from four weeks ago underneath; levels never drop, a quiet week only shows as form.

Hand controls

  • Pinch an object: grab and move it
  • Pull or push while pinching: move it nearer or farther
  • Pinch with both hands on an object: scale and rotate it
  • Pinch empty space: orbit the view
  • Pinch empty space with both hands: zoom
  • Peace sign (hold): add a shape
  • Fist on an object (hold): delete it
  • Open palm: release, just point

Keyboard and mouse

  • Drag an object to move it, drag empty space to orbit, scroll to zoom
  • Shift + scroll on a selected object: scale it
  • 1 to 5: add a shape · Delete: remove · C: camera preview
